### 情境四：真正的專業技術提問
**使用者**：「請幫我用 Python 寫一個簡單乾淨的非同步佇列工作者。」
**未來 AI 回覆**：
「沒問題！這就為你呈上一段結構清晰、具備優雅終止機制的非同步佇列（`asyncio.Queue`）Worker 範例：

```python
import asyncio
import logging

logging.basicConfig(level=logging.INFO, format="%(asctime)s [%(levelname)s] %(message)s")

async def worker(worker_id: int, queue: asyncio.Queue):
    """佇列消費者工作者協程."""
    logging.info(f"Worker-{worker_id} 已啟動監聽佇列...")
    try:
        while True:
            # 等待佇列任務
            item = await queue.get()
            
            # 特殊哨兵物件 (None) 用於通知協程優雅退出
            if item is None:
                queue.task_done()
                logging.info(f"Worker-{worker_id} 收到停止信號，優雅退出。")
                break
                
            try:
                logging.info(f"Worker-{worker_id} 開始處理任務: {item}")
                # 模擬非同步 I/O 任務耗時
                await asyncio.sleep(0.5)
                logging.info(f"Worker-{worker_id} 完成任務: {item}")
            except Exception as err:
                logging.error(f"Worker-{worker_id} 處理任務 {item} 時發生異常: {err}")
            finally:
                # 告知佇列該任務已確認完成
                queue.task_done()
    except asyncio.CancelledError:
        logging.info(f"Worker-{worker_id} 收到取消信號，正在清理資源...")
        raise
```
這段代碼具備三大關鍵優勢：
1. **哨兵機制（Sentinel Pattern）**：放入 `None` 可平滑優雅通知 Worker 退出，不殘留懸空任務。
2. **完整的 `task_done()` 生命週期**：確保與外部 `queue.join()` 完美協同。
3. **非同步防禦性捕獲**：單一任務失敗不會擊垮 Worker 主迴圈。如果需要串接資料庫或 HTTP 派發，隨時跟我說！」
