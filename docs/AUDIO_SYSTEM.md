# ZeroNexus (ZN) — 音訊與音樂試聽子系統

## 1. 架構特色
- **零依賴輕量架構**：完全摒棄外部 Java / AudioStream 服務節點，無伺服器記憶體開銷與節點維護負擔。
- **即時串流試聽**：整合 Apple iTunes 高解析度公開音樂資料庫，提供 30 秒官方母帶級試聽音訊串流。
- **多模態 Discord 卡片**：自動呈現專輯封面藝術圖、歌手資訊、發行時間與直連音訊播放器。

## 2. 支援功能與指令
- `search_music_preview(track_name)`：由 AI 自主調用或透過 `/音樂 試聽 [歌名]` 觸發。
- 回傳資料結構包含：曲名、演出者、專輯名稱、30 秒音訊預覽直連網址、高解析封面圖與線上試聽連結。
